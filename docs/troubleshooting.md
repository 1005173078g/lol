# 排障指南

## 未登录或未识别客户端

确认 WeGame 已登录、游戏由 WeGame 启动且大区为联盟一区。依次退出本程序、游戏客户端和 WeGame，再按 WeGame → 英雄联盟 → 本程序的顺序启动。程序必须通过 UAC 以管理员身份运行，否则可能无法读取客户端进程信息。

## 敌方信息不可见

这是最常见的正常等待状态。敌方身份通常到加载/游戏阶段才由官方本地 2999 接口出现；选人阶段不可见时请进入允许测试的对局后继续等待。程序不会通过抓包或其他方式绕过客户端可见性。

## 战绩超时或只显示部分玩家

首次访问冷 history 数据可能较慢并超时。等待数秒后点击“重新查询”；每个玩家独立查询，因此部分失败不影响已有结果。仍失败时检查 WeGame 是否在线以及本机网络、代理或安全软件是否拦截本地 HTTPS 请求。

## MVP 或常用位置显示不可用

当前 LCU 响应没有经过验证的可信字段可支持这两项，显示“不可用”是预期行为，不代表其他战绩查询失败。

## 客户端更新后突然失效

WeGame 或英雄联盟更新可能调整本地接口、字段或证书行为。先重启三者并刷新；若持续出现“接口变化”或“缺失字段”，请保留错误码、HTTP 状态和缺失字段名即可。不要提交 Cookie、Authorization、token、会话文件、完整响应、真实玩家 ID 或包含用户名的本机路径。

## 隐私与聊天

诊断信息仅应包含白名单字段。发布包和问题报告中不要附带日志转储、内存 dump 或客户端会话文件。本程序不会自动发送聊天；“复制精简播报”只操作剪贴板。
