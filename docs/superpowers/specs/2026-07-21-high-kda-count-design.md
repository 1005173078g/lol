# 高 KDA 场次统计设计

## 目标

在无法从英雄联盟本地战绩接口获得腾讯 MVP/SVP 标记时，使用可复核的逐场 KDA 指标替代“MVP 不可用”。统计范围与现有分析一致：每名玩家最近最多 20 场单双排或灵活排位。

## 统计口径

- 单场 KDA = `(击杀 + 助攻) / max(1, 死亡)`。
- 单场 KDA 大于或等于 `5.0` 时，计为一场“高 KDA”。
- 零死亡按分母 `1` 计算，避免除零且与现有 KDA 计算口径一致。
- 高 KDA 场次数只基于实际返回的排位样本；样本不足 20 场时，分母显示实际场数。
- 该指标不称为 MVP，也不推断腾讯的 MVP/SVP 结果。

## 数据流与界面

`PlayerAnalyzer` 在分析逐场战绩时计算高 KDA 场次数，并把结果写入 `PlayerAnalysis`。播放器卡片将原 MVP 行替换为 `高KDA X/N（≥5.0）`。精简播报加入 `高KDA X场`，并继续遵守现有 180 字限制及字段裁剪顺序。

## 兼容性

- 现有胜率、常用位置、所选英雄近期表现逻辑不变。
- 查询失败、主播模式和空样本继续沿用现有状态处理。
- 旧的可空 `MvpRate` 字段暂时保留，避免扩大本次变更范围；界面和播报不再依赖它。

## 测试

- 刚好 `5.0` 计入高 KDA。
- 低于 `5.0` 不计入。
- 零死亡使用分母 `1`。
- 卡片显示实际高 KDA 场次与样本数。
- 精简播报包含高 KDA 场次，并保持不超过 180 字。
- 全量测试、发布清单验证和安全扫描继续通过。

## WeGame 边界

本功能不抓取 WeGame 私有接口。若未来获得稳定、授权且能返回腾讯 MVP/SVP 标记的数据源，再单独设计真实 MVP 接入；届时不得把本指标与腾讯 MVP 混用。
